    Providers¶

    ip_info can query the 14 providers below. Four require no registration; the rest offer a free tier that needs an API key. Use the name column with --apis to query a specific provider (see Usage).

    Adding API keys¶

    API keys are stored encrypted at rest using the keyring library, so they are never kept in the repository or in plain text.

    To add or update a key, run: 

    ip_info_keys

    Then, select a provider:

    Available providers¶

    Provider --apis name Key Notes
    AbstractAPI.com abstractapicom Required High rate limit (1/sec).
    AbuseIPDB.com abuseipdbcom Required Abuse reports; high limit (1k/day); no location data.
    CriminalIP.io criminalipio Required Good security information; low limit (50/month).
    IP-API.com ipdashapicom Not required High rate limit; supports bulk queries.
    IP2Location.io ip2locationio Optional High limit (1k/day, more with a key); location, ASN, proxy only.
    IPAPI.co ipapico Not required High limit (1k/day); bulk; location and ASN only.
    IPAPI.com ipapicom Required Low limit (100/month); location only.
    IPAPI.is ipapiis Required Security and risk data; high limit (1k/day); bulk.
    IPAPI.org ipapiorg Required High limit (1k/day); bulk.
    IPGeolocation.io ipgeolocationio Required High limit (1k/day); location only.
    IPInfo.io ipinfoio Required No rate limit; location only.
    IPQuery.io ipqueryio Not required High limit; bulk; good security information.
    IPRegistry.co ipregistryco Required Good security information; 100k queries per account.
    VirusTotal.com virustotalcom Required Good security information; trusted provider; low limit (4/min, 500/day).

    Suggesting a provider¶

    Know of a provider that offers API access in a free tier that isn't listed? Contributions are welcome — see CONTRIBUTING.md. Providers that need no key, have a high rate limit, and return good security information (Tor/VPN detection, risk scores, abuse reports) are especially useful.
